Chapter 17: C/C++ Interoperability

While C and C++ are closely related and share syntax origins, they possess fundamentally different linkage rules, type systems, and compiler behaviors. Mastering C/C++ interoperability, resolving name mangling challenges, utilizing the extern "C" directive, and ensuring Application Binary Interface (ABI) compatibility is essential for integrating legacy C libraries into modern C++ systems applications.

17.1 Name Mangling & The C++ Linkage Challenge

When a C compiler compiles a function, it emits an object symbol matching the function name verbatim (e.g., initialize_sensor_subsystem compiles directly to the symbol _initialize_sensor_subsystem on ELF platforms). C++ compilers, however, support function overloading, namespaces, and templates. To distinguish overloaded functions with identical names but different parameter types, C++ compilers encode function signatures into the compiled symbol name, a process known as name mangling.

If a C++ module attempts to link against a compiled C library object without proper linkage specifications, the linker fails with unresolved external symbol errors because the C++ code expects a mangled symbol name while the C library provides a plain, unmangled symbol.

17.2 The `extern "C"` Directive

To instruct a C++ compiler to suppress name mangling for specific functions and export them with C-compatible linkage, developers wrap function declarations in the extern "C" linkage specification block.

Professional header files designed to be compiled by both C and C++ compilers utilize conditional preprocessor guards checking for __cplusplus, wrapping exports automatically so that C compilers ignore the directive while C++ compilers activate C linkage:

#ifndef SHARED_SENSOR_LIBRARY_H
#define SHARED_SENSOR_LIBRARY_H

#include <stdint.h>
#include <stdbool.h>

// Check if the compiler is a C++ compiler.
#ifdef __cplusplus
// Instruct the C++ compiler to use C linkage for enclosed declarations.
extern "C" {
#endif

// Public function prototypes sharing strict C and C++ ABI compatibility.
bool initialize_shared_sensor_node(uint32_t node_identifier, float sampling_rate);
float fetch_latest_telemetry_reading(void);

#ifdef __cplusplus
}
#endif

#endif

17.3 Struct Layout, ABI Compatibility & ODR

Achieving seamless interoperability requires maintaining identical Application Binary Interface (ABI) layouts across language boundaries. When sharing data structures between C and C++ modules, developers must adhere to strict guidelines:

  • Plain Old Data (POD): Structures passed across language boundaries should contain only primitive data types, fixed arrays, or nested POD structs without virtual member functions, constructors, destructors, or private visibility specifiers.
  • Padding and Alignment: Compilers across both toolchains must agree on member alignment rules to prevent structural offset mismatches.
  • The One Definition Rule (ODR): Struct definitions shared between C and C++ must maintain exact field ordering and data widths to prevent memory corruption.

17.7 Additional Example 2: C++ Exception Translation Boundary

C functions cannot catch C++ exceptions, and throwing a C++ exception across a pure C stack boundary results in immediate undefined behavior and program crashes. Production-grade interoperability requires wrapping C++ operations in explicit try/catch blocks and translating exceptions into standard C error code enums:

#include <iostream>
#include <stdexcept>
#include <cstdint>
#include <cstdlib>

#ifdef __cplusplus
extern "C" {
#endif

// Define C-compatible error code enumeration.
typedef enum 
{
    SYSTEM_SUCCESS = 0,
    SYSTEM_ERROR_NULL_POINTER = 1,
    SYSTEM_ERROR_OUT_OF_BOUNDS = 2,
    SYSTEM_ERROR_INTERNAL_EXCEPTION = 3
} system_error_code_t;

// Internal C++ function that might throw exceptions during processing.
void internal_unsafe_processing_logic(uint32_t parameter)
{
    // Validate input parameter defensively.
    if (parameter == 0)
    {
        // Throw a standard C++ exception.
        throw std::invalid_argument("Error: Input parameter cannot be zero.");
    }
}

// C-linkage wrapper function that catches C++ exceptions and translates them to C error codes.
system_error_code_t safe_execute_processing_wrapper(uint32_t parameter)
{
    try
    {
        // Execute unsafe logic inside try block.
        internal_unsafe_processing_logic(parameter);

        // Return success status code.
        return SYSTEM_SUCCESS;
    }
    catch (const std::exception& exception_reference)
    {
        // Log exception details to standard error stream.
        std::cerr << "Caught C++ Exception across boundary: " << exception_reference.what() << "\n";

        // Return translated internal exception error code.
        return SYSTEM_ERROR_INTERNAL_EXCEPTION;
    }
    catch (...)
    {
        // Log unknown exception details.
        std::cerr << "Caught unknown exception across C/C++ boundary.\n";

        // Return error status code.
        return SYSTEM_ERROR_INTERNAL_EXCEPTION;
    }
}

#ifdef __cplusplus
}
#endif

int main(void)
{
    // Test exception translation boundary with zero input parameter.
    system_error_code_t error_status = safe_execute_processing_wrapper(0);

    // Verify error code result.
    if (error_status != SYSTEM_SUCCESS)
    {
        std::cout << "Successfully intercepted C++ exception and received C error code: " << (int)error_status << "\n";
    }

    // Return success status code.
    return EXIT_SUCCESS;
}

17.8 Additional Example 3: C++ Class Method Trampoline Callback

C event-driven libraries expect standard function pointers with C linkage, which cannot directly invoke non-static C++ class member methods because member methods require an implicit this pointer. To bridge this gap, developers use a static trampoline method combined with static_cast on a user context pointer:

#include <iostream>
#include <cstdint>
#include <cstdlib>

// Declare C event dispatcher interface.
extern "C" {
    // Define C-compatible callback function pointer type accepting a user context pointer.
    typedef void (*event_notification_callback_t)(void* user_context, uint32_t event_id);

    // Define static internal callback pointer and context variables.
    static event_notification_callback_t global_registered_callback = nullptr;

    static void* global_user_context_pointer = nullptr;

    // Register C callback function and user context pointer.
    void register_c_event_dispatcher(event_notification_callback_t callback_pointer, void* user_context)
    {
        global_registered_callback = callback_pointer;
        global_user_context_pointer = user_context;
    }

    // Simulate triggering an event from the C system side.
    void trigger_c_event(uint32_t event_id)
    {
        if (global_registered_callback != nullptr)
        {
            global_registered_callback(global_user_context_pointer, event_id);
        }
    }
}

// C++ class managing state and handling events via a static trampoline method.
class SensorEventHandlerManager 
{
    private:
        uint32_t manager_instance_id_;

        // Static trampoline function compatible with C function pointer signature.
        static void handle_c_callback_trampoline(void* user_context, uint32_t event_id)
        {
            // Cast the generic void user context pointer back to our C++ class instance.
            SensorEventHandlerManager* instance = static_cast<SensorEventHandlerManager*>(user_context);

            // Verify instance pointer validity.
            if (instance != nullptr)
            {
                // Forward event notification to member method.
                instance->handle_event_member_method(event_id);
            }
        }

        // Concrete C++ class member method handling the event.
        void handle_event_member_method(uint32_t event_id)
        {
            std::cout << "C++ Class Instance " << manager_instance_id_ 
                      << " successfully handled event ID: 0x" << std::hex << event_id << std::dec << "\n";
        }

    public:
        // Constructor initializing manager instance ID.
        explicit SensorEventHandlerManager(uint32_t identifier) : manager_instance_id_(identifier) 
        {
            std::cout << "SensorEventHandlerManager constructor invoked for ID: " << manager_instance_id_ << "\n";
        }

        // Destructor cleaning up manager instance resources.
        ~SensorEventHandlerManager(void)
        {
            std::cout << "SensorEventHandlerManager destructor invoked for ID: " << manager_instance_id_ << "\n";
        }

        // Method to register this instance with the C system system.
        void register_with_c_system(void)
        {
            // Pass 'this' as the user context pointer and the static trampoline method as the callback.
            register_c_event_dispatcher(&SensorEventHandlerManager::handle_c_callback_trampoline, this);
        }
};

int main(void)
{
    // Instantiate C++ event handler manager class.
    SensorEventHandlerManager handler_instance(9988);

    // Register instance with C system using trampoline callback.
    handler_instance.register_with_c_system();

    // Trigger event from C system side.
    trigger_c_event(0xAA55BB66);

    // Return success status code.
    return EXIT_SUCCESS;
}

/**
 * @brief Computes the functional margin / signed decision distance for a single sample.
 * @param sample Feature vector for query observation.
 * @return Continuous raw decision score (dot product plus bias).
 * @throws std::invalid_argument If sample dimension does not match weight coefficient vector dimension.
 */
double SupportVectorClassifier::compute_decision_value(const std::vector<double>& sample) const
{
    // Ensure the input sample dimension matches trained weight vector dimesion.
    if (sample.size() != weight_coefficients.size())
    {
        throw std::invalid_argument("Input feature vector dimension does not align with trained weight coefficients.");
    }

    // Compute dot product between weight vector and input sample feature vector.
    const double inner_feature_product = std::inner_product(sample.begin(), sample.end(), weight_coefficients.begin(), 0.0);

    // Calculate signed decision score.
    return inner_feature_product + this->intercept_bias;
}

    const double raw_decision_score = compute_decision_value(sample);

    return raw_decision_score >= 0.0 ? 1 : -1;

/**
 * @brief Fits the linear decision boundary to training data via SGD with Hinge Loss.
 * @param features 2D matrix of training observations.
 * @param labels Vector of target binary class labels (-1 or +1).
 * @throws std::invalid_argument If feature dataset or labels are empty, or if sample/label lengths mismatch.
 */
void SupportVectorClassifier::train(const std::vector<std::vector<double>>& features, const std::vector<int>& labels)
{
    // Guard against empty datasets.
    if (features.empty() || labels.empty())
    {
        throw std::invalid_argument("Training feature dataset and target labels must not be empty.");
    }

    // Ensure sample count matches target label count.
    if (features.size() != labels.size())
    {
        throw std::invalid_argument("Dimension mismatch between feature observations and target labels.");
    }

    const std::size_t total_observations = features.size();
    const std::size_t feature_dimension_count = features[0].size();

    // Initialize all model weight coefficients to zero.
    this->weight_coefficients.assign(feature_dimension_count, 0.0);
    this->intercept_bias = 0.0;

    // Main optimization loop running for specified epoch count.
    for (std::size_t step = 0; step < this->maximum_iterations; step++)
    {
        // Stochastic gradient descent: Iterate through each sample sequentially.
        for (std::size_t observation_index = 0; observation_index < total_observations; observation_index++)
        {
            const std::vector<double>& current_feature = features[observation_index];
            const int current_target_label = labels[observation_index];

            // Compute hyperplane dot product.
            const double hyperplane_dot_product = std::inner_product(current_feature.begin(), 
                current_feature.end(), weight_coefficients.begin(), 0.0);

            // Compute functional margin conditions.
            const double margin_value = current_target_label * (hyperplane_dot_product + this->intercept_bias);

            if (margin_value >= 1.0)
            {
                // Correctly classified outside margin: Apply standard L2 regularization weight decay.
                for (std::size_t feature_index = 0; feature_index < feature_dimension_count; feature_index++)
                {
                    const double regularization_gradient = this->weight_coefficients[feature_index] / static_cast<double>(this->maximum_iterations);

                    this->weight_coefficients[feature_index] -= this->learning_rate * regularization_gradient;
                }
            }
            else
            {
                // Misclassified or inside margin: Update weights using hinge loss penalty gradient.
                for (std::size_t feature_index = 0; feature_index < feature_dimension_count; feature_index++)
                {
                    const double regularization_gradient = this->weight_coefficients[feature_index] / static_cast<double>(this->maximum_iterations);
                    const double hinge_loss_gradient = this->regularization_penalty * current_target_label * current_feature[feature_index];

                    this->weight_coefficients[feature_index] -= this->learning_rate * (regularization_gradient - hinge_loss_gradient);
                }

                // Update intercept bias using hinge loss.
                this->intercept_bias += this->learning_rate * this->regularization_penalty * current_target_label;
            }
        }
    }
}

void print_classifier_summary(const SupportVectorClassifier& classifier)
{
    std::cout << "-- Support Vector Classifier --" << std::endl;
    std::cout << "Weight Coefficients: [";

    std::size_t size = classifier.get_weight_coefficients().size();

    std::size_t count = 0;
    
    // Print weight array values with proper spacing and formatting.
    for (double weight : classifier.get_weight_coefficients())
    {   
        if (count < size - 1)
        {
            std::cout << weight << " ";
        }
        else
        {
            std::cout << weight;
        }

        count++;
    }

    std::cout << "]" << std::endl;

    std::cout << "Intercept Bias: " << classifier.get_intercept_bias() << std::endl;
    std::cout << "Learning Rate: " << classifier.get_learning_rate() << std::endl;
    std::cout << "Regularization penalty: " << classifier.get_regularization_penalty() << std::endl;
    std::cout << "Maximum iterations: " << classifier.get_maximum_iterations() << std::endl;
    std::cout << "-------------------------------" << std::endl;
}

/**
 * @file        :   svm_c_wrapper.cpp
 * @author      :   Braiden Gole
 * @brief       :   Implementation of C linkage wrapper functions wrapping the SupportVectorClassifier class.
 * @details     :   Translates C-style flat pointers and error codes into C++ objects and exceptions,
 *                  providing an ABI-safe bridge for C applications to interface with the SGD-trained SVM.
 * @version     :   1.0
 * @date        :   2026-07-30
 */
#include <iostream>
#include <vector>
#include <stdexcept>

// Include the C++ class header and C wrapper header.
#include "support_vector_classifier.hpp"
#include "svm_c_wrapper.h"

// Define the concrete internal structure mapping the opaque C handle to the C++ class.
struct SupportVectorClassifierContext 
{
    SupportVectorClassifier classifier;

    // Parameterized constructor initializing the underlying classifier.
    SupportVectorClassifierContext(double learning_rate, double regularization_penalty, size_t maximum_iterations)
        : classifier(learning_rate, regularization_penalty, maximum_iterations) {}
};

// Enforce C-compatible linkage implementation blocks.
#ifdef __cplusplus
extern "C" {
#endif

svm_classifier_context_t* svm_classifier_create(double learning_rate, double regularization_penalty, size_t maximum_iterations)
{
    try
    {
        // Allocate heap memory for the wrapped C++ classifier context instance.
        return new svm_classifier_context_t(learning_rate, regularization_penalty, maximum_iterations);
    }
    catch (const std::exception& exception_reference)
    {
        std::cerr << "Error allocating SVM classifier context: " << exception_reference.what() << "\n";

        return nullptr;
    }
}

void svm_classifier_destroy(svm_classifier_context_t* context)
{
    if (context != nullptr)
    {
        // Safely reclaim heap memory and invoke destructor.
        delete context;
    }
}

bool svm_classifier_train(svm_classifier_context_t* context, 
                          const double* flat_features_pointer, 
                          const int* labels_pointer, 
                          size_t observation_count, 
                          size_t dimension)
{
    if (context == nullptr || flat_features_pointer == nullptr || labels_pointer == nullptr)
    {
        std::cerr << "Error: Received null pointer reference in svm_classifier_train.\n";

        return false;
    }

    try
    {
        // Reshape flat C array into C++ 2D vector matrix format.
        std::vector<std::vector<double>> training_features(observation_count, std::vector<double>(dimension));

        for (size_t row = 0; row < observation_count; row++)
        {
            for (size_t column = 0; column < dimension; column++)
            {
                training_features[row][column] = flat_features_pointer[row * dimension + column];
            }
        }

        // Reshape target label array into C++ vector format.
        std::vector<int> labels(labels_pointer, labels_pointer + observation_count);

        // Execute training on the underlying C++ classifier instance.
        context->classifier.train(training_features, labels);

        return true;
    }
    catch (const std::exception& exception_reference)
    {
        std::cerr << "Exception caught during SVM training across C boundary: " << exception_reference.what() << "\n";
        return false;
    }
}

int svm_classifier_predict(svm_classifier_context_t* context, const double* features, size_t dimension)
{
    if (context == nullptr || features == nullptr)
    {
        std::cerr << "Error: Received null pointer reference in svm_classifier_predict.\n";

        return -999;
    }

    try
    {
        // Convert flat C sample array into C++ vector format.
        std::vector<double> query_sample(features, features + dimension);

        // Execute prediction using underlying C++ classifier instance.
        return context->classifier.predict_class_label(query_sample);
    }
    catch (const std::exception& exception_reference)
    {
        std::cerr << "Exception caught during SVM prediction across C boundary: " << exception_reference.what() << "\n";

        return -999;
    }
}

/**
 * @file        :   main.cpp
 * @author      :   Braiden Gole
 * @brief       :   Driver script demonstrating training and evaluation of a Support Vector Classifier.
 * @details     :   This program instantiates a linear Support Vector Classifier, trains it on a 2D 
 *                  toy dataset using Stochastic Gradient Descent (SGD) with hinge loss, and outputs 
 *                  the learned model parameters (weights and bias) alongside its hyperparameter summary.
 * Compile:
 * clang++ -Wall -Wextra -Wpedantic ./src/main.cpp ./src/support_vector_classifier.cpp -I./include -o ./bin/support_vector_test
 * @version     :   1.0
 * @date        :   2026-07-30
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

// Include the C-compatible wrapper header.
#include "svm_c_wrapper.h"

int main(void)
{
    printf("Starting Pure C Application Driver for C++ SVM Interoperability...\n");

    // Define dimensions and training dataset parameters.
    size_t observation_count = 6;
    size_t dimension = 2;

    // Flatten 2D feature observations into a continuous 1D C array.
    double features[] = 
    {
        2.0, 3.0,
        1.0, 1.0,
        2.0, 1.0,
        8.0, 9.0,
        7.0, 8.0,
        9.0, 7.0
    };

    // Define target binary class labels.
    int labels[] = {-1, -1, -1, 1, 1, 1};

    // 1. Create classifier instance via C wrapper function (opaque handle).
    svm_classifier_context_t* svm_model = svm_classifier_create(0.001, 100.0, 10000);

    if (svm_model == NULL)
    {
        fprintf(stderr, "Error: Failed to create SVM classifier instance.\n");

        return EXIT_FAILURE;
    }

    // 2. Train model using flat C pointers.
    bool training_success = svm_classifier_train(svm_model, features, labels, observation_count, dimension);

    if (!training_success)
    {
        fprintf(stderr, "Error: SVM model training failed.\n");

        svm_classifier_destroy(svm_model);

        return EXIT_FAILURE;
    }

    printf("SVM Model successfully trained from C driver application!\n");

    // 3. Test predictions on new query samples from C.
    double alpha[] = {1.5, 2.0};
    double beta[]  = {8.5, 8.0};

    int prediction_alpha = svm_classifier_predict(svm_model, alpha, dimension);
    int prediction_beta  = svm_classifier_predict(svm_model, beta, dimension);

    printf("Prediction for Test Sample A [1.5, 2.0] -> Class Label: %d\n", prediction_alpha);
    printf("Prediction for Test Sample B [8.5, 8.0] -> Class Label: %d\n", prediction_beta);

    // 4. Safely destroy model instance and reclaim resources.
    svm_classifier_destroy(svm_model);

    svm_model = NULL;

    printf("C interoperability execution completed successfully.\n");

    return EXIT_SUCCESS;
}

17.10 Summary Checklist

  • Always wrap C library header declarations in extern "C" { ... } blocks conditioned on __cplusplus to prevent linker errors caused by name mangling.
  • Ensure data structures shared across C and C++ modules adhere strictly to Plain Old Data (POD) layouts and matching alignment rules.
  • Validate all configuration pointers and function pointer callbacks defensively against NULL across language boundaries.
  • Compile multi-language projects by compiling C and C++ source files with their respective compilers (gcc / clang vs g++ / clang++) and linking them together into a unified binary.
  • Use opaque pointer handles for strict encapsulation, implement C++ exception translation boundaries to prevent uncaught exceptions across C call stacks, and leverage RAII for leak-proof resource management.

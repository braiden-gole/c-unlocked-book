Chapter 15: Function Pointers, Callbacks & Concurrency

In systems programming, executable machine instructions reside in memory just like data. Function pointers allow programs to treat code as dynamic values, enabling runtime polymorphism, callback architectures, and dynamic dispatch tables. Combined with POSIX threads (pthreads), function pointers provide the foundation for building multi-threaded concurrent execution engines.

15.1 Function Pointer Mechanics & Syntax

Just as a standard pointer stores the memory address of an integer or struct, a function pointer stores the memory address of an executable function entry point. Declaring a function pointer requires matching the signature (return type and parameter list) of the target function precisely:

// Declare a function pointer variable named 'arithmetic_operation_pointer'
// that accepts two integer parameters and returns an integer.
int (*arithmetic_operation_pointer)(int operand_one, int operand_two);

15.2 Callbacks & Higher-Order Functions

Passing function pointers as arguments to other routines creates callbacks. This decoupling allows generic modules (such as sorting algorithms, event listeners, or asynchronous dispatchers) to execute custom user-defined logic without knowing the implementation details beforehand.

15.3 Concurrency Fundamentals with POSIX Threads

Modern multi-core processors demand concurrent execution models. POSIX threads (<pthread.h>) provide standard multi-threading capabilities on UNIX-like and macOS systems. Threads execute concurrent routines starting from a designated thread function taking and returning a void* pointer.

15.4 Comprehensive Systems Demonstration 1: Dynamic Dispatch Table & Telemetry Filter

The first intricate demonstration implements a high-frequency sensor telemetry pipeline using an array of function pointers as a dynamic dispatch table, applying custom data transformation callbacks dynamically:

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <stdbool.h>

// Define a function pointer type for telemetry transformation strategies.
typedef double (*transform_callback_t)(double sensor_reading);

static double apply_kalman_smoothing_filter(double sensor_reading)
{
    // Apply smoothing arithmetic by scaling sensor reading and adding a bias offset.
    double smoothed_reading = sensor_reading * 0.85f + 1.20f;

    // Return the calculated smoothed value.
    return smoothed_reading;
}

static double apply_exponential_amplification_filter(double sensor_reading)
{
    // Multiply input sensor reading by an amplification factor.
    double amplified_reading = sensor_reading * 1.50f;

    // Return the amplified telemetry value.
    return amplified_reading;
}

static double apply_identity_pass_through_filter(double sensor_reading)
{
    // Return input sensor reading unmodified.
    return sensor_reading;
}

static void process_telemetry_stream(const double* stream, double* out_stream, size_t count, transform_callback_t callback)
{
    // Verify input stream, output stream, and callback pointers defensively against null references.
    if (stream == NULL || out_stream == NULL || callback == NULL)
    {
        // Print error message to standard error stream.
        fprintf(stderr, "Error: Received invalid null pointers during telemetry stream processing.\n");

        return;
    }

    // Iterate sequentially through each sample index in the telemetry stream buffer.
    for (size_t index = 0; index < count; index++)
    {
        // Invoke the dynamically bound function pointer callback on current sample element.
        out_stream[index] = callback(stream[index]);
    }
}

int main(void)
{
    // Define constant representing total sample count in streams.
    const size_t sample_count = 5;

    // Initialize raw telemetry input buffer array with sample data.
    double telemetry_data[5] = {10.5, 22.1, 19.8, 31.4, 28.6};

    // Initialize processed telemetry output buffer array with zeros.
    double processed_data[5] = {0.0};

    // Construct a dynamic dispatch table using an array of function pointers.
    transform_callback_t dispatch_table[] =
    {
        apply_identity_pass_through_filter,
        apply_kalman_smoothing_filter,
        apply_exponential_amplification_filter
    };

    // Define descriptive strategy name strings corresponding to dispatch table entries.
    const char* strategy_names[] =
    {
        "Pass-Through",
        "Kalman Smoothing",
        "Exponential Amplification"
    };

    // Print application banner message.
    printf("=== Dynamic Telemetry Dispatch Table Demonstration ===\n\n");

    // Loop through each strategy index in the dispatch table.
    for (int strategy_index = 0; strategy_index < 3; strategy_index++)
    {
        // Print description of active strategy being applied.
        printf("Applying Strategy: %s\n", strategy_names[strategy_index]);

        // Execute higher-order function passing the current function pointer from table.
        process_telemetry_stream(telemetry_data,
                                 processed_data,
                                 sample_count,
                                 dispatch_table[strategy_index]);

        // Print header for output results array.
        printf("-> Output Results: [ ");

        // Iterate through processed array and print each transformed value.
        for (size_t index = 0; index < sample_count; index++)
        {
            printf("%.2f ", processed_data[index]);
        }

        // Print closing bracket for array output.
        printf("]\n\n");
    }

    // Return success exit status code.
    return EXIT_SUCCESS;
}

15.5 Comprehensive Systems Demonstration 2: Multi-Threaded Parallel Dataset Statistics Worker

The second intricate demonstration is a practical systems utility that divides a large dataset partition across multiple concurrent POSIX threads, using function pointer callbacks to execute parallel statistical calculations (such as summation aggregation and peak value detection) with robust error checks:

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <stdbool.h>
#include <pthread.h>

// Define a function pointer type for statistical metric computation callbacks.
typedef double (*statistical_metric_callback_t)(const double* data, size_t count);

static double compute_dataset_sum(const double *data, size_t count)
{
    // Check defensively if data pointer is null.
    if (data == NULL)
    {
        return 0.0;
    }

    // Initialize running sum accumulator variable.
    double running_sum = 0.0;

    // Loop through each element in dataset array to accumulate sum.
    for (size_t index = 0; index < count; index++)
    {
        running_sum += data[index];
    }

    // Return the total accumulated summation value.
    return running_sum;
}

static double compute_dataset_maximum(const double *data, size_t count)
{
    // Verify data pointer is valid and count is greater than zero.
    if (data == NULL || count == 0)
    {
        return 0.0;
    }

    // Initialize peak maximum value with the first array element.
    double peak_value = data[0];

    // Iterate through remaining array elements to find maximum value.
    for (size_t index = 1; index < count; index++)
    {
        // Check if current element exceeds current peak value.
        if (data[index] > peak_value)
        {
            // Update peak value.
            peak_value = data[index];
        }
    }

    // Return discovered peak maximum value.
    return peak_value;
}

// Define a composite thread payload structure for parallel analysis.
typedef struct 
{
    int32_t id;
    const double* partition;
    size_t count;
    double result;
    statistical_metric_callback_t callback;
} thread_analysis_payload_t;

static void* parallel_analysis_worker_routine(void* argument)
{
    // Validate thread argument pointer defensively against null reference.
    if (argument == NULL)
    {
        // Print error message to standard error stream.
        fprintf(stderr, "Error: Parallel analysis worker received null argument pointer.\n");

        return NULL;
    }

    // Cast generic void pointer back to concrete thread analysis payload structure type.
    thread_analysis_payload_t* analysis_record = (thread_analysis_payload_t*)argument;

    // Verify callback and partition pointer validity before execution.
    if (analysis_record->callback != NULL && analysis_record->partition != NULL)
    {
        // Execute assigned statistical metric callback function on partition data.
        analysis_record->result = analysis_record->callback(
            analysis_record->partition, 
            analysis_record->count
        );
    }
    else
    {
        // Set result to zero if callback or partition is invalid.
        analysis_record->result = 0.0;
    }

    // Return null thread exit pointer.
    return NULL;
}

int main(void)
{
    // Print startup banner message.
    printf("=== Initializing Parallel Dataset Statistics Engine ===\n\n");

    // Define constant for total elements in master dataset.
    const size_t total_elements = 8;

    // Initialize master dataset array with sample numerical values.
    double master_dataset[8] = { 12.5, 45.2, 8.1, 99.4, 33.0, 77.1, 14.9, 52.8 };

    // Calculate partition size for dividing dataset across threads.
    size_t partition_size = total_elements / 2;

    // Declare POSIX thread identifier variables.
    pthread_t summation_thread_identifier;
    pthread_t maximum_thread_identifier;

    // Allocate heap memory for summation thread payload record.
    thread_analysis_payload_t* summation_payload_record = (thread_analysis_payload_t*)malloc(sizeof(thread_analysis_payload_t));

    // Defensively check heap allocation success for summation payload.
    if (summation_payload_record == NULL)
    {
        // Print error message to standard error stream.
        fprintf(stderr, "Error: Heap allocation failed for summation thread payload record.\n");

        return EXIT_FAILURE;
    }

    // Populate summation thread payload record fields.
    summation_payload_record->id = 1;
    summation_payload_record->partition = &master_dataset[0];
    summation_payload_record->count = partition_size;
    summation_payload_record->result = 0.0;
    summation_payload_record->callback = compute_dataset_sum;

    // Allocate heap memory for maximum thread payload record.
    thread_analysis_payload_t* maximum_payload_record = (thread_analysis_payload_t*)malloc(sizeof(thread_analysis_payload_t));

    // Defensively check heap allocation success for maximum payload.
    if (maximum_payload_record == NULL)
    {
        // Print error message to standard error stream.
        fprintf(stderr, "Error: Heap allocation failed for maximum thread payload record.\n");

        // Free previously allocated summation payload memory before exiting.
        free(summation_payload_record);

        return EXIT_FAILURE;
    }

    // Populate maximum thread payload record fields.
    maximum_payload_record->id = 2;
    maximum_payload_record->partition = &master_dataset[partition_size];
    maximum_payload_record->count = partition_size;
    maximum_payload_record->result = 0.0;
    maximum_payload_record->callback = compute_dataset_maximum;

    // Spawn concurrent POSIX threads for parallel analysis execution.
    int32_t summation_spawn_status = pthread_create(&summation_thread_identifier, NULL, parallel_analysis_worker_routine, (void *)summation_payload_record);
    int32_t maximum_spawn_status = pthread_create(&maximum_thread_identifier, NULL, parallel_analysis_worker_routine, (void *)maximum_payload_record);

    // Defensively verify thread creation status codes.
    if (summation_spawn_status != 0 || maximum_spawn_status != 0)
    {
        // Print error message to standard error stream.
        fprintf(stderr, "Error: Failed to spawn parallel data analysis threads.\n");

        // Reclaim heap memory allocated for thread payloads.
        free(summation_payload_record);
        free(maximum_payload_record);

        return EXIT_FAILURE;
    }

    // Print thread synchronization status message.
    printf("Main thread waiting for parallel worker threads to complete analysis...\n\n");

    // Synchronize worker threads using pthread_join.
    pthread_join(summation_thread_identifier, NULL);
    pthread_join(maximum_thread_identifier, NULL);

    // Print computed parallel analysis results.
    printf("Parallel Computation Results:\n");
    printf("- Partition One Summation Result: %.2f\n", summation_payload_record->result);
    printf("- Partition Two Maximum Result  : %.2f\n", maximum_payload_record->result);

    // Reclaim heap memory allocated for payloads and nullify pointers.
    free(summation_payload_record);

    summation_payload_record = NULL;

    free(maximum_payload_record);

    maximum_payload_record = NULL;

    // Print successful completion message.
    printf("\nParallel dataset analysis completed successfully. Engine shut down.\n");

    // Return success status code.
    return EXIT_SUCCESS;
}

15.6 Summary Checklist

  • Function pointers store exact executable memory addresses, enabling dynamic dispatch tables and runtime polymorphism.
  • Higher-order functions accept function pointers as arguments, cleanly decoupling algorithms from specific callback logic.
  • Use POSIX threads (pthread_create and pthread_join) to achieve true concurrent multi-threaded execution.
  • Always allocate distinct payload records on the heap when spawning multiple concurrent threads to prevent data races and memory corruption.

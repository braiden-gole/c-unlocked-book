Chapter 8: Structures, Unions & Enums

User-defined data types allow C developers to group disparate variables into cohesive logical units, share single memory locations across alternative types, and enforce strict state constants. Mastering structures, unions, and enumerations is essential for building complex systems architectures.

8.1 Structures: Grouping Heterogeneous Data

Unlike arrays that enforce a single uniform data type across all elements, a **structure** (struct) in C enables developers to bundle variables of differing types into a single composite data record. Members reside sequentially in memory, subject to compiler padding and alignment rules.

Structures serve as the foundational mechanism for modeling complex objects, network packet headers, and hardware register maps. Accessing structure members utilizes either the dot operator (.) for direct instances or the arrow operator (->) when working with pointers.

The following example demonstrates declaring and instantiating a basic structure to model sensor attributes:

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <string.h>

// Define a composite structure representing a sensor device record.
typedef struct 
{
    uint32_t id;
    float baseline_reading;
    char location_tag[32];
} sensor_device_record_t;

int main(void)
{
    // Instantiate and initialize a structure record.
    sensor_device_record_t primary_sensor = 
    {
        .id = 4001,
        .baseline_reading = 23.5f
    };

    snprintf(primary_sensor.location_tag, sizeof(primary_sensor.location_tag), "%s", "SectorAlpha");

    printf("Sensor ID: %u | Reading: %.2f | Location: %s\n",
           primary_sensor.id,
           primary_sensor.baseline_reading,
           primary_sensor.location_tag);

    return EXIT_SUCCESS;
}

8.2 Unions: Sharing Memory Across Alternative Types

A **union** shares structural syntax with a struct, but its underlying memory behavior is fundamentally different: all members of a union occupy the exact same physical memory location.

The total memory size of a union equals the size of its largest individual member. Unions are indispensable in systems programming for low-level hardware communication, variant telemetry data interpretation, and type-punning.

The following example illustrates how mutating one member of a union immediately affects the values of all other members due to shared memory overlapping, allowing us to inspect raw byte arrays directly:

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>

// Define a union where all members share the same memory location.
typedef union 
{
    uint32_t value;
    float decimal;
    uint8_t byte_array[4];
} shared_memory_variant_t;

int main(void)
{
    shared_memory_variant_t container;

    // Assign a value to the integer member.
    container.value = 0x41200000;

    printf("Interpreted as Integer: 0x%08X\n", container.value);
    printf("Interpreted as Float  : %.2f\n", container.decimal);
    
    printf("Interpreted as Bytes  : ");

    for (size_t index = 0; index < 4; index++)
    {
        printf("0x%02X ", container.byte_array[index]);
    }

    printf("\n");

    return EXIT_SUCCESS;
}

8.3 Enumerations: Type-Safe Symbolic Constants

An **enumeration** (enum) creates a set of named integer constants, improving code readability and replacing unmanaged magic numbers. By default, enumerators begin at integer value 0 and increment sequentially, though explicit values can be assigned at declaration.

The following example demonstrates defining operational state enums and using them inside a conditional evaluation switch statement:

#include <stdio.h>
#include <stdlib.h>

// Define type-safe symbolic constants using enums for operational states.
typedef enum 
{
    SYSTEM_STATE_INITIALIZING = 0,
    SYSTEM_STATE_RUNNING = 1,
    SYSTEM_STATE_FAULT = 2,
    SYSTEM_STATE_SHUTDOWN = 3
} system_operational_state_t;

int main(void)
{
    // Initialize current system operational state variable to running state.
    system_operational_state_t current_system_state = SYSTEM_STATE_RUNNING;

    // Route execution flow based on the current operational state enum value.
    switch (current_system_state)
    {
        case SYSTEM_STATE_INITIALIZING:
            // Handle component initialization sequence.
            printf("System Status: Initializing components...\n");
            break;

        case SYSTEM_STATE_RUNNING:
            // Handle nominal operational status.
            printf("System Status: Operational parameters nominal.\n");
            break;

        case SYSTEM_STATE_FAULT:
            // Handle critical fault condition.
            printf("System Status: Critical fault detected!\n");
            break;

        case SYSTEM_STATE_SHUTDOWN:
            // Handle safe power down sequence.
            printf("System Status: System safely powered down.\n");
            break;

        default:
            // Defensively handle unexpected or corrupted state values.
            fprintf(stderr, "Error: Unknown or corrupted system state encountered: %d\n", (int)current_system_state);
            return EXIT_FAILURE;
    }

    // Return success status code upon normal execution completion.
    return EXIT_SUCCESS;
}

8.4 Comprehensive Systems Demonstration: Packet Parser with Structs, Unions & Enums

The following detailed systems demonstration illustrates combining enums, structures, and unions to parse variant network sensor packets safely:

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <stdbool.h>

// Define enumeration for telemetry packet payload types.
typedef enum 
{
    PACKET_TYPE_TEMPERATURE = 0,
    PACKET_TYPE_VOLTAGE = 1,
    PACKET_TYPE_STATUS = 2
} packet_type_t;

// Define a union allowing variant interpretation of payload data bytes.
typedef union 
{
    float temperature_celsius;
    uint32_t voltage_millivolts;
    uint8_t status_code_byte;
} packet_payload_data_t;

// Define a composite structure representing a structured network packet header and body.
typedef struct 
{
    uint16_t packet_id;
    packet_type_t type;
    packet_payload_data_t payload;
} sensor_telemetry_packet_t;

// Function prototype for parsing and processing telemetry packets.
bool process_sensor_telemetry_packet(const sensor_telemetry_packet_t* const packet);

int main(void)
{
    // Initialize a temperature telemetry packet instance.
    sensor_telemetry_packet_t temperature_packet =
    {
        .packet_id = 0x010A,
        .type = PACKET_TYPE_TEMPERATURE,
        .payload.temperature_celsius = 78.5f
    };

    // Initialize a voltage telemetry packet instance.
    sensor_telemetry_packet_t voltage_packet =
    {
        .packet_id = 0x010B,
        .type = PACKET_TYPE_VOLTAGE,
        .payload.voltage_millivolts = 3300
    };

    printf("--- Processing Network Sensor Telemetry Packets ---\n");

    // Process temperature packet.
    if (!process_sensor_telemetry_packet(&temperature_packet))
    {
        fprintf(stderr, "Error: Failed to process temperature telemetry packet.\n");

        return EXIT_FAILURE;
    }

    // Process voltage packet.
    if (!process_sensor_telemetry_packet(&voltage_packet))
    {
        fprintf(stderr, "Error: Failed to process voltage telemetry packet.\n");

        return EXIT_FAILURE;
    }

    printf("All telemetry packets successfully parsed and processed.\n");

    return EXIT_SUCCESS;
}

bool process_sensor_telemetry_packet(const sensor_telemetry_packet_t* const packet)
{
    // Validate pointer integrity defensively.
    if (packet == NULL)
    {
        fprintf(stderr, "Error: Received null pointer in packet processing routine.\n");
        
        return false;
    }

    printf("Processing Packet ID: 0x%04X | ", packet->packet_id);

    // Switch on packet type enum to interpret union payload data correctly.
    switch (packet->type)
    {
        case PACKET_TYPE_TEMPERATURE:
            printf("Type: TEMPERATURE | Value: %.2f °C\n", packet->payload.temperature_celsius);
            break;

        case PACKET_TYPE_VOLTAGE:
            printf("Type: VOLTAGE | Value: %u mV\n", packet->payload.voltage_millivolts);
            break;

        case PACKET_TYPE_STATUS:
            printf("Type: STATUS | Value: 0x%02X\n", packet->payload.status_code_byte);
            break;

        default:
            fprintf(stderr, "Error: Unknown packet type encountered.\n");
            return false;
    }

    return true;
}

8.5 Advanced Systems Demonstration: Managing a Dynamic Entity Registry with Nested Structs, Enums & Heap Allocation

Systems software frequently requires grouping related states using nested structures and enums, and managing collections of these composite records dynamically on the heap. Combining Chapter 7 heap management rules with Chapter 8 data structures allows us to allocate, populate, query, and release dynamic entity registries safely.

The following systems program demonstrates nested structures, enum-governed operational states, dynamic heap allocation, defensive validation, and proper memory deallocation:

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <stdbool.h>
#include <string.h>

// Define enumeration for entity operational states.
typedef enum
{
    ENTITY_STATE_IDLE = 0,
    ENTITY_STATE_ACTIVE = 1,
    ENTITY_STATE_CRITICAL = 2,
    ENTITY_STATE_OFFLINE = 3
} entity_state_t;

// Define a nested structure representing physical spatial coordinates.
typedef struct
{
    float x;
    float y;
    float z;
} spatial_vector_3d_t;

// Define a composite structure representing a registered system entity record.
typedef struct
{
    uint32_t id;
    char name[32];
    entity_state_t state;
    spatial_vector_3d_t position;
} system_entity_record_t;

// Function prototypes adhering to strict pointer contracts.
system_entity_record_t* allocate_entity_registry(size_t number_of_records);
bool update_entity_position(system_entity_record_t* const entity, float x, float y, float z);
void print_entity_record(const system_entity_record_t *const entity);

int main(void)
{
    size_t registry_capacity = 3;

    // Allocate entity registry array dynamically on the heap.
    system_entity_record_t* entity_registry = allocate_entity_registry(registry_capacity);

    if (entity_registry == NULL)
    {
        fprintf(stderr, "Error: Failed to allocate memory for entity registry.\n");

        return EXIT_FAILURE;
    }

    // Populate entity records using designated initializers and member notation.
    entity_registry[0] = (system_entity_record_t)
    {
        .id = 1001,
        .state = ENTITY_STATE_ACTIVE,
        .position = {10.5f, 20.0f, 5.2f}
    };

    snprintf(entity_registry[0].name, sizeof(entity_registry[0].name), "%s", "AlphaSensorNode");

    entity_registry[1] = (system_entity_record_t)
    {
        .id = 1002,
        .state = ENTITY_STATE_CRITICAL,
        .position = {-45.2f, 12.8f, 100.0f}
    };

    snprintf(entity_registry[1].name, sizeof(entity_registry[1].name), "%s", "BetaRelayStation");

    entity_registry[2] = (system_entity_record_t)
    {
        .id = 1003,
        .state = ENTITY_STATE_IDLE,
        .position = {0.0f, 0.0f, 0.0f}
    };

    snprintf(entity_registry[2].name, sizeof(entity_registry[2].name), "%s", "GammaGateway");

    printf("--- Initial System Entity Registry Records ---\n");

    for (size_t index = 0; index < registry_capacity; index++)
    {
        print_entity_record(&entity_registry[index]);
    }

    // Mutate an entity position using pointer reference and update function.
    if (!update_entity_position(&entity_registry[2], 15.5f, 30.2f, 10.1f))
    {
        fprintf(stderr, "Error: Failed to update entity position.\n");

        free(entity_registry);

        entity_registry = NULL;

        return EXIT_FAILURE;
    }

    printf("\n--- Updated System Entity Registry Records ---\n");

    print_entity_record(&entity_registry[2]);

    // Safely release heap memory (every malloc/allocation requires a matching free).
    free(entity_registry);

    // Nullify pointer immediately after free to prevent dangling reference bugs.
    entity_registry = NULL;

    printf("\nEntity registry heap memory successfully released and pointer nullified.\n");

    return EXIT_SUCCESS;
}

system_entity_record_t* allocate_entity_registry(size_t number_of_records)
{
    // Validate bounds defensively.
    if (number_of_records == 0)
    {
        return NULL;
    }

    // Allocate memory block on the heap using malloc.
    system_entity_record_t* registry_pointer = (system_entity_record_t*)malloc(number_of_records * sizeof(system_entity_record_t));

    // Defensively check if malloc succeeded.
    if (registry_pointer == NULL)
    {
        fprintf(stderr, "Error: Heap allocation for entity registry failed.\n");

        return NULL;
    }

    return registry_pointer;
}

bool update_entity_position(system_entity_record_t* const entity, float x, float y, float z)
{
    // Validate pointer integrity defensively.
    if (entity == NULL)
    {
        return false;
    }

    // Mutate nested structure position members using arrow operator.
    entity->position.x = x;
    entity->position.y = y;
    entity->position.z = z;

    return true;
}

void print_entity_record(const system_entity_record_t* const entity)
{
    // Validate pointer integrity defensively.
    if (entity == NULL)
    {
        return;
    }

    // Map entity state enum to human-readable string representation.
    const char* state = "UNKNOWN";

    switch (entity->state)
    {
        case ENTITY_STATE_IDLE:
            state = "IDLE";
            break;
        case ENTITY_STATE_ACTIVE:
            state = "ACTIVE";
            break;
        case ENTITY_STATE_CRITICAL:
            state = "CRITICAL";
            break;
        case ENTITY_STATE_OFFLINE:
            state = "OFFLINE";
            break;
    }

    printf("Entity ID: %u | Name: %-18s | State: %-8s | Position: (%.1f, %.1f, %.1f)\n",
           entity->id,
           entity->name,
           state,
           entity->position.x,
           entity->position.y,
           entity->position.z);
}

8.6 Summary Checklist

  • Use structures (struct) to bundle heterogeneous variables into cohesive, composite records.
  • Use unions (union) when multiple alternative variables must share the exact same physical memory location.
  • Use enumerations (enum) to replace magic numbers with clean, type-safe symbolic state constants.
  • Always pass structures and composite records to functions via pointers combined with const qualifiers to avoid expensive copy overhead.
  • Every call to malloc() (or allocation functions) managing dynamic structure registries requires a matching call to free() to prevent memory leaks.

C Unlocked

Mastering Pointers, Memory Architecture, and Low-Level Systems Programming

Written by Braiden Gole

braiden.gole@gmail.com braiden-gole.github.io braiden-gole

Part I: Foundations & Core Syntax

Chapter 1: The C Environment & Compilation Pipeline

Preprocessing, compilation to assembly, assembling to object code, and linking into an executable binary using GCC/Clang.

Chapter 2: Primitive Types, Variables & Memory Representation

Exact-width integers (stdint.h), IEEE 754 floating points, signed vs. unsigned arithmetic, endianness, and memory layout.

Chapter 3: Operators, Expressions & Control Flow

Precedence traps, short-circuit evaluation, branching (if, switch), loops, and writing predictable, branch-friendly logic.

Chapter 4: Functions, Scope & The Call Stack

Stack frames, pass-by-value semantics, storage classes (static, extern), recursion limits, and how the CPU tracks execution flow.

Part II: Memory, Pointers & Data Layout

Chapter 5: Pointers Demystified

Memory addresses, dereferencing (* and &), pointer arithmetic, void *, const correctness, and eliminating null-pointer crashes.

Chapter 6: Arrays, Strings & Buffer Safety

Pointer decay, contiguous memory layouts, null-terminated C strings, and replacing unsafe legacy functions (strcpy) with bounded alternatives (snprintf).

Chapter 7: Dynamic Memory Allocation & Heap Management

Escaping stack boundaries with malloc, calloc, realloc, and free; preventing memory leaks, double-frees, and dangling pointers.

Chapter 8: Structs, Unions & Memory Alignment

Composite data types, struct padding, cache-line alignment, bit-fields, and overlapping memory spaces with unions.

Part III: Modularity, I/O & Tooling

Chapter 9: File I/O & Stream Processing

Buffered streams (FILE *), binary vs. text mode, random file access (fseek, ftell), standard streams, and errno error handling.

Chapter 10: The Preprocessor & Macro Metaprogramming

#define, conditional compilation (#ifdef), header guards, variadic macros, and avoiding macro side-effect bugs.

Chapter 11: Multi-File Architecture & Build Systems

Separating interfaces (.h) from implementations (.c), managing translation units, static/shared libraries (.a, .so), and Makefiles.

Chapter 12: Debugging & Memory Sanitizers

Inspecting live state with GDB/LLDB, hunting leaks with Valgrind, and catching undefined behavior with AddressSanitizer (ASan) and UBSan.

Part IV: Advanced Systems & C/C++ Interoperability

Chapter 13: Error Handling & Assertions

Explicit status return codes, custom enums, system error propagation via errno, and runtime invariant validation with <assert.h>.

Chapter 14: Bitwise Operations & Low-Level Optimization

Bitwise operators (&, |, ^, ~, <<, >>), bitmasks, hardware register flags, and branchless programming tricks.

Chapter 15: Function Pointers, Callbacks & Concurrency

Dynamic dispatch tables, generic algorithms (qsort patterns), and multi-threaded programming using POSIX threads (pthreads) and atomics.

Chapter 16: Data Structures from Scratch

Implementing self-referential structs, intrusive linked lists, dynamic arrays, ring buffers, and hash tables with manual memory ownership.

Chapter 17: C & C++ Interoperability: Bridging Both Worlds

Integrating C libraries into C++ using extern "C", preventing name mangling, managing ABI boundaries, and wrapping raw C pointers in RAII classes.

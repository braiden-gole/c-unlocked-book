Chapter 6: Arrays, Strings & Memory Buffers

Arrays, strings, and contiguous memory buffers form the data backbone of C systems applications. Understanding physical RAM layout, avoiding pointer decay pitfalls, and enforcing strict bounds checking is essential for writing high-performance, secure systems code.

6.1 Array Allocation, Contiguity & Indexing Fundamentals

An array in C is a fixed-size, contiguous sequence of memory locations holding elements of identical data types. Elements reside directly side-by-side in RAM without internal padding or header metadata, allowing traversal via index lookups or pointer arithmetic to execute with maximum hardware efficiency.

Declaring an array like int32_t sensor_readings[5]; instructs the compiler to reserve a contiguous block of exactly 5 * sizeof(int32_t) bytes in memory. The following detailed systems demonstration illustrates multidimensional array layout, matrix initialization, row-major traversal, and defensive bounds verification:

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <stdbool.h>

int main(void)
{
    // Define row and column dimensions for a hardware sensor grid matrix.
    const size_t matrix_rows = 3;
    const size_t matrix_columns = 3;

    // Allocate a contiguous 2D array representing a spatial sensor grid.
    int32_t sensor_grid[3][3] = 
    {
        {10, 20, 30},
        {40, 50, 60},
        {70, 80, 90}
    };

    // Print header label for the grid scanner output.
    printf("--- Scanning Hardware Sensor Grid Matrix ---\n");

    // Traverse the 2D array using nested loops in row-major order.
    for (size_t row_index = 0; row_index < matrix_rows; row_index++)
    {
        for (size_t column_index = 0; column_index < matrix_columns; column_index++)
        {
            // Access each grid element using standard subscript notation.
            int32_t current_reading = sensor_grid[row_index][column_index];

            // Print coordinate position and stored value.
            printf("Grid Cell [%zu][%zu] -> Value: %d\n", row_index, column_index, current_reading);
        }
    }

    // Return success status code to the operating system environment.
    return EXIT_SUCCESS;
}

6.2 Pointer Decay & Passing Arrays to Functions

A critical trap for C developers involves pointer decay. Passing an array identifier into a function argument strips away compile-time size metadata, degrading the array into a raw pointer pointing to its first element (e.g., decaying from int32_t[5] to int32_t*).

The receiving function acquires only a raw memory address, meaning that calling sizeof(array_parameter) inside that function evaluates to the size of the pointer itself rather than the total size of the allocated buffer. Systems functions operating on arrays must therefore accept an explicit size_t size parameter to enforce strict safety bounds.

The following detailed systems demonstration illustrates safe array transmission, explicit bounds tracking, and defensive mutation across function boundaries:

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <stdbool.h>

// Function prototype accepting an array pointer as argument 1 and explicit element count as argument 2.
bool normalize_sensor_buffer(int32_t* const buffer, size_t size, int32_t scaling_multiplier);

int main(void)
{
    // Allocate a local contiguous telemetry buffer.
    int32_t telemetry_buffer[] = {100, 200, 300, 400, 500};
    
    // Calculate total elements in main() where array size is fully known.
    size_t count = sizeof(telemetry_buffer) / sizeof(telemetry_buffer[0]);

    // Define scaling multiplier constant.
    const int32_t amplifier_gain = 2;

    // Print initial unscaled buffer values.
    printf("Original buffer values: ");

    for (size_t index = 0; index < count; index++)
    {
        printf("%d ", telemetry_buffer[index]);
    }

    printf("\n");

    // Invoke normalization routine protecting against buffer overflows.
    bool status = normalize_sensor_buffer(telemetry_buffer, count, amplifier_gain);

    if (!status)
    {
        // Print descriptive error message to standard error stream.
        fprintf(stderr, "Error: Buffer normalization failed due to null pointer or invalid bounds.\n");

        // Terminate execution returning a standard failure status code.
        return EXIT_FAILURE;
    }

    // Print successfully scaled buffer values.
    printf("Normalized buffer values: ");

    for (size_t index = 0; index < count; index++)
    {
        printf("%d ", telemetry_buffer[index]);
    }

    printf("\n");

    // Return success status code to the operating system.
    return EXIT_SUCCESS;
}

bool normalize_sensor_buffer(int32_t* const buffer, size_t size, int32_t scaling_multiplier)
{
    // Validate pointer integrity and size bounds defensively.
    if (buffer == NULL || size == 0)
    {
        return false;
    }

    // Iterate through the buffer safely using the explicit element count parameter.
    for (size_t index = 0; index < size; index++)
    {
        // Multiply each element value by the scaling factor.
        buffer[index] *= scaling_multiplier;
    }

    // Return success status.
    return true;
}

6.3 Character Strings & Null-Terminated Buffers

Unlike higher-level programming languages that manage string objects with built-in length metadata, C strings consist of contiguous arrays of characters terminated explicitly by a null byte character ('\0', ASCII value 0). Algorithms determine string length by scanning memory sequentially until locating this null terminator byte.

Standard library functions like strcpy() and sprintf() fail to verify destination buffer capacities, creating severe security vulnerabilities. Modern defensive C systems programming mandates the use of bounds-checked alternatives such as snprintf().

When formatting and printing strings or scalar values using functions like printf(), fprintf(), or snprintf(), C relies on specific format specifiers to interpret variable data types correctly across different architectures and bit widths. The comprehensive table below outlines all essential string, character, integer, long, floating-point, size, and pointer format specifiers used throughout systems programming:

Format Specifier Corresponding Data Type Description & Systems Usage Example
%s char* (String) Prints a null-terminated character string. Example: printf("%s", "Active");
%c char Prints a single character. Example: printf("%c", 'A');
%d or %i int (Signed standard integer) Prints signed decimal integers. Example: printf("%d", -42);
%u unsigned int Prints unsigned decimal integers. Example: printf("%u", 1024);
%ld long (Signed long integer) Prints signed long integers. Example: printf("%ld", file_offset);
%lu unsigned long Prints unsigned long integers. Example: printf("%lu", total_bytes);
%lld long long (Signed 64-bit integer) Prints signed long long integers. Example: printf("%lld", epoch_timestamp);
%llu unsigned long long Prints unsigned long long integers. Example: printf("%llu", memory_limit);
%zu size_t Prints memory sizes and array counts (corresponds to sizeof). Example: printf("%zu", buffer_size);
%f float / double Prints floating-point numbers in standard decimal notation. Example: printf("%.2f", 98.6f);
%lf double (in scanf / optional in printf) Scans or prints double-precision floats. Example: scanf("%lf", &precise_value);
%x or %X Unsigned integer types Prints hexadecimal integers (lowercase %x or uppercase %X). Example: printf("0x%08X", device_id);
%p void* (Pointer) Prints raw memory addresses in hexadecimal format. Example: printf("%p", (void*)&variable);

The following comprehensive systems demonstration illustrates safe string manipulation, bounds checking, explicit null-termination enforcement, and custom token parsing across mutable character buffers:

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <stdbool.h>
#include <string.h>

// Function prototype for parsing a delimited key-value string safely.
bool parse_delimited_string(char* const buffer, size_t buffer_size, 
                            char* const key_output, size_t key_output_size, 
                            uint32_t* const output);

int main(void)
{
    // Allocate a mutable character buffer storing raw key-value data.
    char stream[64] = "device_node_alpha:115200";

    char extracted_key[32] = {0};

    uint32_t parsed_value = 0;

    // Parse the delimited string defensively.
    bool status = parse_delimited_string(
        stream, 
        sizeof(stream), 
        extracted_key, 
        sizeof(extracted_key), 
        &parsed_value
    );

    // Check the parsed status.
    if (!status)
    {
        fprintf(stderr, "Error: Failed to parse delimited string.\n");

        return EXIT_FAILURE;
    }

    // Summary.
    printf("--- Successfully Parsed Key-Value String ---\n");
    printf("- Extracted Key   : %s\n", extracted_key);
    printf("- Parsed Value    : %u\n", parsed_value);

    return EXIT_SUCCESS;
}

bool parse_delimited_string(char* const buffer, size_t buffer_size, 
                            char* const key_output, size_t key_output_size, 
                            uint32_t* const output)
{
    // Validate pointer arguments and buffer capacity defensively.
    if (buffer == NULL || key_output == NULL || output == NULL || buffer_size == 0)
    {
        return false;
    }

    // Search for the delimiter colon character (':') within the mutable string buffer.
    char* delimiter = strchr(buffer, ':');

    if (delimiter == NULL)
    {
        fprintf(stderr, "Error: Missing expected delimiter colon in string.\n");

        return false;
    }

    // Temporarily replace the colon with a null terminator to isolate the key substring.
    *delimiter = '\0';

    // Copy the key portion safely into the destination storage buffer with bounds checking.
    int print_status = snprintf(key_output, key_output_size, "%s", buffer);

    if (print_status < 0 || (size_t)print_status >= key_output_size)
    {
        fprintf(stderr, "Error: Key storage buffer capacity exceeded during copy.\n");

        return false;
    }

    // Advance past the null terminator to point directly to the numeric value string portion.
    char* value = delimiter + 1;

    // Convert the numeric string representation into an integer using standard library functions.
    char* conversion_end = NULL;

    long converted_numeric_value = strtol(value, &conversion_end, 10);

    // Verify that conversion succeeded and consumed characters.
    if (value == conversion_end || converted_numeric_value <= 0)
    {
        fprintf(stderr, "Error: Invalid numeric value format encountered in string.\n");

        return false;
    }

    *output = (uint32_t)converted_numeric_value;

    return true;
}

    const char* const directory = "/var/log/telemetry";

    bool status = join_file_path(complete_file_path, capacity, directory, filename);

    // Verify that path joining executed successfully without errors.
    if (!status)
    {
        fprintf(stderr, "Error: Failed to construct file path securely.\n");

    printf("Successfully constructed file path: %s\n", complete_file_path);

    return EXIT_SUCCESS;

bool join_file_path(char* const destination, size_t capacity, 
                    const char* const directory_path, const char* const filename)
{
    // Validate pointer arguments and buffer capacity defensively.
    if (destination == NULL || directory_path == NULL || filename == NULL || capacity == 0)
    {
        return false;
    }

    // Format and combine path strings safely with bounds checking.
    int character_count = snprintf(destination, capacity, "%s/%s", directory_path, filename);

6.5 Advanced Raw Buffer Byte Manipulation & Memory Copying

Systems software frequently requires raw byte manipulation when parsing network protocol packets, serializing binary structures, or moving raw memory chunks between device registers. Developers accomplish this safely using memory utility routines like memcpy() combined with strict boundary validation.

The following detailed systems demonstration illustrates safe raw byte buffer slicing, copying, and validation:

#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <stdbool.h>
#include <string.h>

// Function prototype for slicing a raw byte stream buffer.
bool extract_packet_payload(const uint8_t* const source, size_t source_size, 
                            uint8_t* const destination, size_t destination_size, 
                            size_t payload_offset, size_t payload_length);

int main(void)
{
    // Initialize a raw source byte stream buffer.
    uint8_t data[64] = 
    {
        0xAA, 0xBB, 0xCC, 0xDD,
        0x01, 0x02, 0x03, 0x04,
        0x05, 0x06, 0x07, 0x08
    };

    size_t size = sizeof(data);

    // Allocate a destination buffer to hold the sliced data segment.
    uint8_t destination_data[8];
    size_t destination_capacity = sizeof(destination_data);

    // Define byte offset and transfer length parameters.
    size_t byte_offset = 4;
    size_t byte_count = 8;

    // Extract the buffer slice safely using bounds-checked memory copying.
    bool status = extract_packet_payload(data, size, destination_data, destination_capacity, byte_offset, byte_count);

    if (!status)
    {
        // Print error message to standard error stream.
        fprintf(stderr, "Error: Buffer slice extraction failed due to bounds overflow or null pointers.\n");

        // Terminate program execution returning a standard failure status code.
        return EXIT_FAILURE;
    }

    // Print confirmation and display extracted bytes in hexadecimal format.
    printf("Successfully extracted buffer bytes: ");

    for (size_t index = 0; index < byte_count; index++)
    {
        printf("0x%02X ", destination_data[index]);
    }

    printf("\n");

    // Return success status code to operating system environment.
    return EXIT_SUCCESS;
}

bool extract_packet_payload(const uint8_t* const source, size_t source_size, 
                          uint8_t* const destination, size_t destination_size, 
                          size_t payload_offset, size_t payload_length)
{
    // Validate pointer integrity defensively.
    if (source == NULL || destination == NULL)
    {
        return false;
    }

    // Verify that the requested extraction range does not exceed source buffer boundaries.
    if ((payload_offset + payload_length) > source_size)
    {
        return false;
    }

    // Verify that the destination buffer has sufficient capacity to hold the data.
    if (payload_length > destination_size)
    {
        return false;
    }

    // Perform secure, bounds-checked memory copying from source offset to destination.
    memcpy(destination, source + payload_offset, payload_length);

    // Return success status.
    return true;
}

6.6 Summary Checklist

  • Arrays decay to pointers when passed to functions; always pass an explicit size_t count parameter alongside array pointers.
  • Character buffers allocated for strings must reserve space for the mandatory null terminator ('\0').
  • Unsafe legacy string functions like strcpy and sprintf create critical security vulnerabilities; always use bounds-checked alternatives like snprintf.
  • Buffer capacity and pointer parameters must be validated defensively against NULL and boundary overflows before performing write operations.
